## Descripción

Prototipo de consola desarrollado en Python para registrar, buscar, ordenar y actualizar encomiendas, validar datos y almacenar registros en archivos de texto.

## Funcionalidades

- Registro y consulta de encomiendas.
- Validación de DNI y códigos únicos.
- Búsqueda y actualización de estados.
- Ordenamiento mediante Bubble Sort.
- Almacenamiento y carga de datos desde archivos de texto.
